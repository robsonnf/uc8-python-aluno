# UC8: Desenvolver e organizar interface gráfica para aplicações desktop — Aluno

[Acessar as aulas online](https://robsonnf.github.io/uc8-python-aluno/).

Matéria: Python · Tkinter e ttk.

Extraia a pasta inteira, preservando assets e lessons. Abra index.html ou, com Node 18+, execute npm start nesta pasta. Não é necessário npm install. Ctrl+C encerra o servidor. Se npm.ps1 estiver bloqueado no PowerShell, use npm.cmd start, sem alterar políticas do sistema.

P alterna a grade e Escape fecha. A correção será conduzida pelo professor; este pacote não contém gabaritos.

O seletor Tema no topo permite escolher Claro ou Escuro. A preferência visual acompanha os links locais e pode ser guardada neste navegador. Rascunhos, respostas e anotações continuam sem salvamento automático. A impressão usa fundo claro.

O editor permite editar, copiar, baixar e reiniciar rascunhos. Não executa programas ou práticas da matéria. Siga a ferramenta e a forma de verificação indicadas na atividade. Baixar salva somente aquele arquivo. Exportar registros inclui respostas, anotações e rascunhos modificados; não recolhe arquivos externos nem envia ao professor.

Sem salvamento automático: baixe/exporte antes de recarregar ou fechar. Use dados fictícios, confira o arquivo e envie pelo canal combinado. As páginas e anexos locais funcionam offline; fontes externas precisam de internet. Sem JS, texto e enunciados continuam disponíveis, mas os controles de registro/exportação não funcionam.

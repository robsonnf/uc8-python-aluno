Entenda a ideia e faça um ensaio ↗

1. Problema concreto

Um produto mudou de nome. Você deve criar outro cadastro ou alterar o produto que já existe?

2. Entenda a ideia

CRUD é a abreviação das operações criar, ler, atualizar e excluir. Nesta aula você completará essas operações para produtos e iniciará inclusão e listagem de clientes.

Atualizar modifica uma linha existente. Seu ID permanece o mesmo; nome e preço podem mudar. Sem essa distinção, o botão Salvar pode criar duplicatas em vez de editar.

UPDATE ... WHERE id=? informa qual linha deve mudar. Confira rowcount, a quantidade de linhas afetadas, para não anunciar uma edição que não encontrou o ID.

A seleção da tela guarda o ID escolhido. O comando Novo limpa campos e seleção; salvar sem seleção inclui, e salvar com seleção edita.

3. Exemplo comentado

Editar sem criar outro ID
produtos = {12: {"nome": "Copo", "preco_centavos": 200}}

Regras e detalhes para consultar durante o desafio

Complete no repositório as operações criar, ler, atualizar e excluir. A interface mantém a seleção do ID e só redesenha a listagem após o resultado. Produtos recebem CRUD completo; clientes começam com inclusão/listagem para evoluir na A16.

CRUD reúne criar, ler, atualizar e excluir. Editar significa alterar uma linha existente por ID, não inserir outra com o nome novo. O nome pode mudar sem que a identidade do produto mude.

Use UPDATE ... WHERE id=? com nome e preço validados antes de gravar. Confira rowcount para tratar um ID removido ou inexistente; não apresente sucesso quando nenhuma linha correspondeu à seleção.

Seleção é uma intenção da interface e pode ficar desatualizada. Atualizar a listagem deve conservar a relação por ID ou pedir nova seleção. Não use posição da Treeview como chave do banco.

O comando Novo limpa campos e seleção para cadastrar outra linha. Salvar com seleção edita; salvar sem seleção inclui. Mostre essa distinção ao operar e inclua uma tentativa inválida para comprovar que o registro anterior permaneceu.

Desafio individual: confira a lógica ↗

Cadastre dois produtos, selecione um pelo ID e altere nome/preço. Reordene linhas e repita a edição. Feche/reabra o banco e verifique que apenas o ID pretendido mudou, sem linha duplicada.

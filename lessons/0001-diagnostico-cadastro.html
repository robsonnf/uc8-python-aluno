Antes da aula — Teoria

Leitura obrigatória antes dos desafios. Reserve cerca de 10 min.

Conceito

Um programa recebe texto e precisa conferir o que ele significa antes de aceitar a entrada. Uma função dá nome a uma tarefa e devolve seu resultado. int tenta transformar texto em inteiro; quando isso não é possível, ValueError informa a falha. try/except permite orientar a correção. Na janela, o clique chama uma função que lê os campos e mostra a resposta. Conferir uma entrada não significa gravar um cadastro em arquivo.

Exemplo mínimo comentado

Conferir um número de caixas, sem janela

def conferir_caixas(texto):  # Recebe o que foi digitado.
    try:
        valor = int(texto.strip())  # Converte antes de comparar.
    except ValueError:
        return "Corrija o número de caixas."
    if valor < 1:
        return "Use um inteiro positivo."
    return f"Caixas: {valor}"

# Um caso por vez permite comparar previsão e resultado.
for tentativa in (" 4 ", "abc", "0"):
    print(conferir_caixas(tentativa))

Execute separado do cadastro, em ensaio.py. O exemplo trata uma quantidade de caixas. No desafio, você ainda precisa conferir nome e idade e ligar a resposta ao botão; o site não executa esse programa.

Resultado esperado do ensaio
Caixas: 4
Corrija o número de caixas.
Use um inteiro positivo.

Três erros comuns

  1. Comparar texto com número sem fazer a conversão necessária.
  2. Tentar converter sem tratar a falha e encerrar a tentativa com traceback.
  3. Usar parênteses ao atribuir o callback e executar a função durante a montagem da janela.

Texto e número no terminal ↗

Cerca de 5 min

"18" + "1" dá "181". int("18") + 1 dá 19. O campo entrega texto. Converta a idade para poder comparar com zero.

  1. Ler o texto
  2. Limpar e converter
  3. Conferir as regras
  4. Devolver a mensagem
Exemplo resolvido · inscrição numa oficina
def conferir_inscricao(apelido, vagas_digitadas):
    apelido = apelido.strip()  # Retira espaços das pontas.
    if not apelido:
        return "Informe um apelido."

    try:
        vagas = int(vagas_digitadas)  # Aqui a conversão pode falhar.
    except ValueError:
        return "Digite um número inteiro de vagas."

    if vagas <= 0:
        return "Peça ao menos uma vaga."
    return f"Inscrição de {apelido}: {vagas} vaga(s)."

print(conferir_inscricao(" Nani ", "2"))
print(conferir_inscricao("   ", "2"))
print(conferir_inscricao("Nani", "duas"))
print(conferir_inscricao("Nani", "0"))

Salve como oficina.py e rode python oficina.py. Cada chamada recebe dois textos e devolve uma mensagem. No desafio, troque o apelido pelo nome e as vagas pela idade.

Resultado esperado deste exemplo
Inscrição de Nani: 2 vaga(s).
Informe um apelido.
Digite um número inteiro de vagas.
Peça ao menos uma vaga.

Atenção. int() pode gerar ValueError quando recebe letras, vazio ou um decimal. O except trata a conversão. Depois, confira se o inteiro é maior que zero.

Experimente. Preveja o que sai com " 3 " no lugar de "2". Execute e compare. Depois use a mesma sequência para conferir nome e idade.

Ir para o desafio

Regras e detalhes

strip() tira espaços das pontas. Ana Maria continua com o espaço entre as palavras.

O parâmetro recebe um valor quando a função é chamada. return devolve o resultado e encerra a função.

Na A01, aceite uma idade inteira maior que zero. O formulário só confere os dados durante a execução.

Do clique à mensagem na janela ↗

Cerca de 5 min

Digite Nani e clique em Conferir. O texto abaixo muda para Recebi: Nani. A função que o botão chama é o callback.

  1. Clicar no botão
  2. Chamar a função
  3. Ler o campo com get()
  4. Atualizar o rótulo
Exemplo resolvido · ler um campo no clique
import tkinter as tk
from tkinter import ttk

janela = tk.Tk()
janela.title("Inscrição na oficina")
ttk.Label(janela, text="Apelido fictício").pack()
campo = ttk.Entry(janela)
campo.pack()
mensagem = ttk.Label(janela, text="Aguardando clique.")

def responder():
    apelido = campo.get()  # Lê o que está no campo agora.
    mensagem.configure(text=f"Recebi: {apelido}")

ttk.Button(janela, text="Conferir", command=responder).pack()
mensagem.pack()
janela.mainloop()

Salve como evento.py e rode python evento.py. Use Nani no campo e confira se o rótulo mostra Recebi: Nani.

Atenção. Escreva command=responder. Com command=responder(), a função roda quando o botão é criado.

Experimente. Digite outro apelido e preveja o novo texto antes de clicar. No desafio, leia os dois campos e mostre a mensagem da sua função conferir.

Ir para o desafio

Regras e detalhes

Entry é a caixa de digitação. Label mostra um texto. Button dispara a ação.

Este exemplo usa pack para manter o código curto. No cadastro inicial, grid coloca os elementos em linhas e colunas.

Percorra os controles com Tab e Shift+Tab. Confira o foco e leia a mensagem após um erro.

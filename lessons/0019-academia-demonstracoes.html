Conferir o banco copiado ↗

Cerca de 5 min

Encontrar um arquivo de cópia é o primeiro passo. Abra a cópia por outra conexão e consulte um registro conhecido.

  1. Escolher um destino novo
  2. Copiar pela conexão
  3. Abrir a cópia
  4. Comparar um registro conhecido
Exemplo resolvido · conferir o banco copiado
import sqlite3
origem = sqlite3.connect(":memory:")
copia = sqlite3.connect(":memory:")
origem.execute("CREATE TABLE alunos (nome TEXT)")
origem.execute("INSERT INTO alunos VALUES (?)", ("Lia",))
origem.commit()
origem.backup(copia)
print(copia.execute("SELECT nome FROM alunos").fetchone()[0])
print(origem.execute("SELECT count(*) FROM alunos").fetchone()[0])
origem.close()
copia.close()

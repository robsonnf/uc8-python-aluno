Produtos com um detalhe a mais ↗

Cerca de 5 min

Pizza e bebida têm código, nome e preço. A pizza também tem tamanho. O pedido continua calculando preço vezes quantidade.

  1. Reaproveitar os dados comuns
  2. Acrescentar o tamanho
  3. Montar os itens
  4. Conferir o total
Exemplo resolvido · produtos com um detalhe a mais
pizza = {"codigo": 31, "nome": "Mussarela",
         "tamanho": "Média", "centavos": 3500}
bebida = {"codigo": 40, "nome": "Suco", "centavos": 600}
itens = [(pizza, 1), (bebida, 2)]
total = sum(produto["centavos"] * qtd for produto, qtd in itens)
print(pizza["nome"], pizza["tamanho"])
print(total)

Salve como ensaio-a10-logic.py e execute no terminal. Compare a saída com a previsão antes de adaptar a ideia ao desafio.

  2. Ler os valores
  3. Chamar a regra

Exemplo resolvido · o evento chama a mesma regra
def receber(acao, valores):
    if acao == "Adicionar":
        return f"Código {valores['codigo']}, quantidade {valores['qtd']}"
    return "Pedido preservado."

print(receber("Adicionar", {"codigo": 31, "qtd": "2"}))
print(receber("Cancelar", {}))

Conceito

Subtotal é o valor dos itens antes do desconto; total é o resultado da forma escolhida. Cada prévia deve partir do subtotal original, preservando produtos e quantidades. Decimal criado a partir de texto representa a conta decimal sem começar por uma aproximação de float. quantize define as casas finais e ROUND_HALF_UP decide o arredondamento do meio centavo. As regras de desconto desta aula são fictícias; não incluem cálculo de troco.

Exemplo mínimo comentado

Dividir um valor e arredondar ao final

from decimal import Decimal, ROUND_HALF_UP

def metade(texto):
    valor = Decimal(texto)  # Comece pelo texto recebido.
    resultado = valor / Decimal("2")
    return resultado.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

original = "2.35"
print("Parte:", metade(original))
print("Repetição:", metade(original))  # Mesma base, mesmo resultado.
print("Original:", original)
# O ensaio não altera o valor que recebeu.

O ensaio divide um valor, não implementa as formas de pagamento do desafio. Compare o resultado bruto e o apresentado, sem modificar o pedido. As quatro formas e os limites continuam nas regras da aula.

Resultado esperado do ensaio
Parte: 1.18
Repetição: 1.18
Original: 2.35

Três erros comuns

  1. Criar Decimal a partir de um float já aproximado.
  2. Descontar novamente sobre um total que já recebeu desconto.
  3. Alterar o pedido para montar uma prévia ou arredondar em etapas que mudam a regra.

Pagamento com duas casas ↗

Cerca de 5 min

Neste exercício, PIX conserva 87% do subtotal. Para R$ 25,00, a prévia é R$ 21,75.

  1. Receber o subtotal
  2. Aplicar o fator da forma
  3. Arredondar para centavos
  4. Devolver a prévia
Exemplo resolvido · pagamento com duas casas
from decimal import Decimal, ROUND_HALF_UP

def previa_pix(texto):
    base = Decimal(texto)
    total = (base * Decimal("0.87")).quantize(
        Decimal("0.01"), rounding=ROUND_HALF_UP)
    return base, total

print(*previa_pix("25.00"))
print(*previa_pix("25.00"))

Regras e detalhes

Os fatores do exercício são 0.87 para Dinheiro e PIX, 0.92 para Débito e 1.00 para Crédito 1x.

Use Decimal criado de texto e ROUND_HALF_UP para centavos. Subtotal, desconto e total precisam corresponder à mesma chamada.

A prévia usa o subtotal original. Repetir a chamada ou trocar de forma preserva itens e quantidades.

Trocar a forma sem acumular desconto ↗

Cerca de 5 min

A sequência PIX, crédito e PIX deve voltar à mesma prévia de PIX. Cada cálculo parte do subtotal original.

  1. Ler a forma
  2. Consultar o subtotal
  3. Calcular outra prévia
  4. Mostrar sem alterar itens
Exemplo resolvido · trocar a forma sem acumular desconto
from decimal import Decimal
subtotal = Decimal("100.00")
for forma, fator in (("PIX", "0.87"), ("Crédito 1x", "1.00"),
                     ("PIX", "0.87")):
    total = subtotal * Decimal(fator)
    print(forma, f"{total:.2f}")
print("Subtotal:", subtotal)

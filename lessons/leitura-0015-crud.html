Editar o mesmo cadastro ↗

Cerca de 5 min

Copo virou Copo azul. O nome muda, mas o ID identifica o mesmo produto e a lista continua com um registro.

  1. Selecionar o ID
  2. Ler a edição
  3. Atualizar pelo ID
  4. Consultar o mesmo registro
Exemplo resolvido · editar o mesmo cadastro
produtos = {12: {"nome": "Copo", "preco_centavos": 200}}
codigo = 12
produtos[codigo].update(nome="Copo azul", preco_centavos=250)
print("ID:", codigo)
print("Registros:", len(produtos))
print(produtos[codigo]["nome"], produtos[codigo]["preco_centavos"])

Salve como ensaio-a15-logic.py e execute no terminal. Compare a saída com a previsão antes de adaptar a ideia ao desafio.

Resultado esperado deste exemplo
ID: 12
Registros: 1
Copo azul 250

Atenção. Use UPDATE com o ID selecionado. Criar outro registro ao editar produziria uma duplicata.

Experimente. Mude também o preço. Confira a quantidade de registros e o ID depois da alteração.

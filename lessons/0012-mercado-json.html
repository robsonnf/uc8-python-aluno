Antes da aula — Teoria

Leitura obrigatória antes dos desafios. Reserve cerca de 10 min.

Conceito

Um arquivo guarda texto em um caminho. Ao gravar, escolhemos o texto e sua codificação; ao ler, recuperamos esse texto. JSON transforma dados em texto estruturado e permite fazer o caminho de volta. Depois da leitura, ainda é preciso conferir os dados e suas regras. Uma falha não deve sobrescrever o original nem apagar a tentativa. Trocar abas do Notebook muda a apresentação, preservando o pedido já criado.

Exemplo mínimo comentado

Gravar e ler JSON em uma pasta temporária

import json
from pathlib import Path
from tempfile import TemporaryDirectory

# A pasta de ensaio será removida ao terminar este bloco.
with TemporaryDirectory() as pasta:
    caminho = Path(pasta) / "cores.json"
    texto = json.dumps([{"id": 4, "nome": "Lilás"}], ensure_ascii=False)
    caminho.write_text(texto, encoding="utf-8")
    lido = caminho.read_text(encoding="utf-8")
    dados = json.loads(lido)  # Texto volta a ser dados.
    print(dados[0]["id"], dados[0]["nome"])
print("Ensaio encerrado")

O exemplo cria somente sua pasta temporária, sem usar o catálogo do projeto. write_text grava texto; read_text recupera texto; loads decodifica JSON. O desafio acrescenta validação do catálogo, escrita temporária/substituição e preservação em falhas.

Resultado esperado do ensaio
4 Lilás
Ensaio encerrado

Três erros comuns

  1. Confundir texto JSON decodificado com dados já validados.
  2. Apagar um arquivo inválido ou substituí-lo por vazio automaticamente.
  3. Recriar o pedido ao navegar ou anunciar sucesso ao cancelar o seletor.

Dados e texto JSON ↗

Cerca de 5 min

Uma lista Python pode virar texto para ser salva. Ao ler, o texto precisa voltar a ser uma lista antes de conferir produtos e preços.

  1. Ler o arquivo como texto
  2. Transformar com json.loads
  3. Conferir os dados
  4. Aceitar o catálogo inteiro
Exemplo resolvido · dados e texto json
import json
catalogo = [{"id": 8, "nome": "Caneta", "preco_centavos": 250}]
texto = json.dumps(catalogo, ensure_ascii=False)
lido = json.loads(texto)
print(type(lido).__name__)
print(lido[0]["nome"], lido[0]["preco_centavos"])

Produto, quantidade e subtotal ↗

Cerca de 5 min

Um picolé de 500 centavos, comprado duas vezes, produz subtotal de 1000 centavos. O produto guarda o preço e o item guarda a quantidade.

  1. Escolher o produto
  2. Conferir a quantidade
  3. Criar ou atualizar o item
  4. Somar os subtotais
Exemplo resolvido · produto, quantidade e subtotal
class ProdutoEnsaio:
    def __init__(self, codigo, nome, preco):
        self.codigo = codigo
        self.nome = nome
        self.preco = preco

class ItemEnsaio:
    def __init__(self, produto, quantidade):
        self.produto = produto
        self.quantidade = quantidade
    def subtotal(self):
        return self.produto.preco * self.quantidade

picole = ProdutoEnsaio(1, "Fruta", 500)
item = ItemEnsaio(picole, 2)
print(item.produto.nome, item.subtotal())

Ir para o desafio

Regras e detalhes

Produto guarda código, nome e preço em centavos. Item guarda produto e quantidade. Pedido reúne os itens e soma os subtotais.

Aceite quantidade inteira de 1 a 999. Repetir o código acumula na mesma linha, conservando esse limite.

Dois pedidos têm coleções próprias. Códigos diferentes continuam distintos mesmo com nomes iguais.

Entenda a ideia e faça um ensaio ↗

1. Problema concreto

Depois de ordenar a tabela, a primeira linha passou a mostrar outro produto. Como evitar editar o produto errado?

2. Entenda a ideia

Posição é onde a linha aparece; identidade é qual produto ela representa. A posição pode mudar. O código do produto deve continuar o mesmo.

Treeview é a tabela visual do ttk. Cada linha tem um identificador chamado iid. Use o código do produto nesse identificador, em vez de usar o número da posição.

selection() devolve os identificadores selecionados. Pode devolver uma tupla vazia quando ninguém selecionou nada; confira esse caso antes de acessar o primeiro elemento.

Adicionar soma unidades ao item; Atualizar quantidade substitui sua quantidade; Remover retira aquele código. São ações diferentes, com testes diferentes.

3. Exemplo comentado

Identidade depois de mudar a ordem
ordem_visual = [41, 92]
selecionado = 41  # Guarde o código, não a posição zero.
ordem_visual.reverse()  # A ordem das linhas mudou.
print(ordem_visual)
print("Produto selecionado:", selecionado)

Regras e detalhes para consultar durante o desafio

O modelo continua responsável por itens e totais. Duas Treeview representam catálogo e carrinho, com iid igual ao código do produto. O callback transforma a seleção em ID e pede a operação ao modelo; a posição visual não identifica o produto.

Treeview apresenta linhas e colunas. headings define os rótulos e insert inclui uma linha; iid identifica essa linha. Use o ID do produto como iid, em vez de confiar no índice que aparece depois de ordenar ou mover uma linha.

selection() devolve os identificadores selecionados. Com selectmode="browse", trate a tupla vazia antes de acessar o primeiro elemento. Diferencie selecionar no catálogo, para adicionar, de selecionar no carrinho, para atualizar ou remover.

O carrinho mantém uma linha por código; repetir o código soma a quantidade. Atualizar substitui a quantidade daquela linha, sem somar; remover exclui só o ID selecionado. Os três comandos têm contratos diferentes e precisam de casos próprios.

Depois de aceitar uma operação, recalcule o total do modelo e redesenhe a listagem. Se o ID ainda existir, pode restaurar a seleção. Remover o último item deve produzir carrinho vazio e total zero, sem tentar acessar uma linha que desapareceu.

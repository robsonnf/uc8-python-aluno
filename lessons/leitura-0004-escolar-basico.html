Antes da aula — Teoria

Leitura obrigatória antes dos desafios. Reserve cerca de 10 min.

Conceito

Uma lista reúne valores em ordem. Um laço permite conferir uma entrada por vez; uma lista nova recebe os números aceitos durante a tentativa. sum soma e len conta; a média divide esses dois resultados. A confirmação só deve mudar depois de conferir o conjunto inteiro. Zero pode ser um valor válido e é diferente de campo vazio. Na atividade, também precisam ser conferidas a identificação e a quantidade exata de cinco notas.

Exemplo mínimo comentado

Percorrer três medidas antes de calcular

textos = ["2", "0", "4"]  # Um ensaio menor que o desafio.
medidas = []
for texto in textos:
    numero = float(texto)
    if not 0 <= numero <= 10:
        raise ValueError("Medida fora da faixa do ensaio.")
    medidas.append(numero)  # A lista da tentativa é nova.

media = sum(medidas) / len(medidas)
print("Quantidade:", len(medidas))
print(f"Média: {media:.1f}")
# No desafio, trate também falha de conversão e cinco campos.

Este ensaio usa somente textos numéricos e três medidas. A mudança proposital para fora da faixa interrompe com ValueError para localizar a conferência; no aplicativo, trate a falha com orientação. Complete cinco notas, identificação e preservação após erro.

Resultado esperado do ensaio
Quantidade: 3
Média: 2.0

Três erros comuns

  1. Usar uma média antes de terminar a conferência de todas as notas.
  2. Confundir zero com ausência e recusar uma nota permitida.
  3. Modificar a lista confirmada enquanto ainda está conferindo a tentativa.

Uma lista para as notas ↗

Cerca de 5 min

As notas 6, 8 e 10 somam 24. Dividir por três dá média 8. No desafio, você usará cinco notas.

  1. Ler as notas
  2. Conferir cada uma
  3. Somar a lista
  4. Dividir pela quantidade
Exemplo resolvido · uma lista para as notas
def media(notas):
    if len(notas) != 3:
        return "Este ensaio pede três notas."
    if any(nota < 0 or nota > 10 for nota in notas):
        return "Use notas de 0 a 10."
    return sum(notas) / len(notas)

print(media([6, 8, 10]))
print(media([6, 8, 11]))

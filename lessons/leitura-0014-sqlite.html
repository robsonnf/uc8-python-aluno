Antes da aula — Teoria

Leitura obrigatória antes dos desafios. Reserve cerca de 10 min.

Conceito

Persistência é conservar os dados depois de encerrar e abrir a aplicação. SQLite guarda registros em um banco; o repositório concentra as operações de gravação e consulta. Parâmetros separam os valores do comando SQL. A confirmação da gravação precisa acontecer antes de anunciar sucesso. JSON representa dados estruturados em texto; CSV apresenta linhas e colunas para intercâmbio; SQLite permite operações e consultas no banco. Nesta aula, o pedido ainda permanece em memória.

Exemplo mínimo comentado

Separar comando SQL e valor recebido

import sqlite3

con = sqlite3.connect(":memory:")  # Banco só para este ensaio.
con.execute("CREATE TABLE marcas (id INTEGER PRIMARY KEY, nome TEXT)")
nome = "D'água"
# O valor é passado separado do comando, sem concatenação.
con.execute("INSERT INTO marcas (nome) VALUES (?)", (nome,))
con.commit()
linha = con.execute("SELECT id, nome FROM marcas").fetchone()
print(linha[0], linha[1])
con.close()
# No desafio, reabra o MESMO caminho de banco em arquivo.

Este banco em memória existe somente enquanto a conexão está aberta. A atividade usa um arquivo de banco e exige reabertura para comprovar persistência; não atribua esse comportamento ao ensaio em memória.

Resultado esperado do ensaio
1 D'água

Três erros comuns

  1. Concatenar o valor digitado dentro do comando SQL.
  2. Anunciar sucesso antes de confirmar a gravação ou depois de uma falha.
  3. Reabrir outro caminho e concluir que o registro desapareceu.

Produto gravado no banco ↗

Cerca de 5 min

Uma variável desaparece quando o programa termina. Um banco em arquivo pode ser aberto de novo para consultar o mesmo produto.

  1. Abrir a conexão
  2. Enviar dados por parâmetros
  3. Confirmar a gravação
  4. Consultar o produto
Exemplo resolvido · produto gravado no banco
import sqlite3
con = sqlite3.connect(":memory:")  # Ensaio isolado.
con.execute("CREATE TABLE produtos (id INTEGER PRIMARY KEY, nome TEXT)")
con.execute("INSERT INTO produtos VALUES (?, ?)", (1, "D'água"))
con.commit()
linha = con.execute("SELECT nome FROM produtos WHERE id=?", (1,)).fetchone()
print(linha[0])
con.close()

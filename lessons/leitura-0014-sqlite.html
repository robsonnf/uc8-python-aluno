Arquitetura e primeiro passo ↗

repositorio.py abre conexões, cria tabelas e executa SQL parametrizado. main.py coleta nome/preço e atualiza a Treeview após a gravação. pagamento.py fornece a interpretação monetária; o banco armazena preco_centavos inteiro.

Uma tabela reúne registros com colunas definidas. A chave primária id identifica cada produto; nome é apresentação e pode se repetir. Não presuma SQL anterior: desenhe duas linhas de produtos e identifique quais valores pertencem a cada coluna.

Conecte a um arquivo fictício escolhido para o projeto e crie a tabela com IF NOT EXISTS. Isso não deve apagar dados existentes. Mantenha o caminho explícito: caminhos relativos à pasta do terminal podem fazer parecer que os dados desapareceram quando, na verdade, outro arquivo foi aberto.

Use INSERT com placeholders ? e uma tupla de valores. Texto como Picolé d'água é dado, não parte da sintaxe SQL. Não monte SQL concatenando nomes ou preços digitados; valide o requisito e deixe a biblioteca associar os parâmetros.

Uma operação de gravação deve confirmar a transação ou desfazê-la em caso de erro. with con trata commit/rollback, mas não fecha a conexão sozinho; combine-o com closing ou fechamento explícito. A importação do módulo não deve criar banco nem abrir janela.

  1. Desenhar o contrato

    Identifique entrada, responsabilidade, resultado e o que deve ser preservado no erro.

  2. Prever um caso conhecido

    Tabela criada sem apagar linhas existentes.

  3. Executar antes da integração

    Use dados fictícios e registre a diferença entre previsão e observado, sem depender da aparência da tela.

  4. Investigar o contraste

    Execute um caso inválido ou cancelado depois do válido e confira todos os dados afetados.

from contextlib import closing
import sqlite3
with closing(sqlite3.connect(":memory:")) as con, con:

Intervalo e integração ↗

Acrescente uma aba Produtos ao seu projeto, com nome, preço, Salvar e listagem. O preço de entrada é texto decimal; converta para centavos inteiros antes de chamar a persistência. Preço vazio, zero, negativo ou com casas extras é recusado. O limite didático de preço unitário é R$100.000,00, equivalente a 10000000 centavos.

A listagem usa ID como iid. Depois de gravar, consulte novamente o repositório e redesenhe a Treeview. Mensagem de sucesso e limpeza do formulário devem acontecer depois da operação concluída, não antes de descobrir erro de gravação.

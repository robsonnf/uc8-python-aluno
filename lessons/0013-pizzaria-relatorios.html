Entenda a ideia e faça um ensaio ↗

1. Problema concreto

Um produto se chama Picolé; edição verão. Se o ponto e vírgula separa colunas, como exportar esse nome sem quebrar a linha do relatório?

2. Entenda a ideia

CSV organiza texto em linhas e colunas. O módulo csv cuida das aspas necessárias quando um valor contém o próprio separador; montar a linha com concatenação pode dividir um nome em duas colunas.

O relatório deve usar o comprovante confirmado. Ler os campos atuais poderia misturar uma montagem nova com uma venda anterior.

No exemplo, delimiter=";" escolhe ponto e vírgula. newline="" evita interferências nas quebras de linha. No arquivo do exercício, UTF-8 com BOM ajuda as ferramentas previstas a reconhecer os acentos.

Leia o CSV de volta para conferir nomes, quantidades e valores. Uma falha ao exportar não deve apagar o pedido nem substituir um relatório anterior por conteúdo incompleto.

3. Exemplo comentado

Escrever e ler um nome com separador
import csv
from io import StringIO

arquivo = StringIO(newline="")  # Um arquivo de texto só na memória para ensaiar.
writer = csv.writer(arquivo, delimiter=";")
writer.writerow(["nome", "quantidade"])
writer.writerow(["Amostra; especial", 2])  # O nome contém o separador.
arquivo.seek(0)  # Volte ao início para ler o que foi escrito.
linhas = list(csv.DictReader(arquivo, delimiter=";"))
print(linhas[0]["nome"])
print(linhas[0]["quantidade"])

Regras e detalhes para consultar durante o desafio

relatorios.py transforma um comprovante confirmado em linhas CSV; não lê widgets atuais. perfis.py mantém uma simulação de identificação/perfil. A pizzaria encerra a transferência e a sorveteria recebe o mesmo contrato de exportação.

Um relatório precisa de fonte definida: use o comprovante confirmado, com os itens e valores daquela finalização. Alterar campos ou começar outra montagem não deve reescrever o retrato que foi escolhido para exportar.

CSV contém linhas e colunas de texto; use csv.writer em vez de concatenar valores com separadores. Configure delimiter=";", newline="" e UTF-8 com BOM quando precisar abrir o exemplo em ferramentas que esperam essa identificação de encoding.

O contrato das colunas inclui ID, nome, quantidade, preço/subtotal em centavos, forma e total do pedido com duas casas. Os centavos continuam inteiros; a convenção precisa aparecer no cabeçalho e no README para quem consumir o arquivo.

Texto com acento, ponto e vírgula ou aspas exige uma leitura de volta com csv.DictReader para conferir a estrutura. A escrita usa temporário e substituição, sem apagar um relatório anterior quando ocorrer falha. É um comprovante didático, sem valor fiscal.

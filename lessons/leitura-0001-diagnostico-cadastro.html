exposição 1: ler, prever e executar ↗

1. Problema concreto

Uma pessoa digita o nome com espaços nas pontas; outra deixa o campo só com espaços. Como preparar o texto antes de decidir se ele pode ser aceito?

2. Entenda a ideia

O programa recebe o texto exatamente como foi digitado. "18" é texto; 18 é um número. Precisamos escolher quando trabalhar com cada um: o nome continua texto e a idade precisa virar número antes da comparação.

Uma função dá nome a uma tarefa. O parâmetro é a entrada recebida; return entrega o resultado para quem chamou. Escrever def prepara a tarefa; a chamada com parênteses é que a executa.

strip() cria um texto sem espaços nas pontas. Se havia apenas espaços, o resultado é "", um texto vazio. if permite escolher uma resposta para cada situação. A validação é essa conferência das regras antes de aceitar a entrada.

Para a idade, int tenta transformar texto em inteiro. Letras e texto vazio podem causar ValueError. try/except permite tratar essa falha; depois da conversão ainda será preciso verificar se a idade é maior que zero.

3. Exemplo comentado

Texto limpo e texto vazio
def preparar_texto(texto):
    # Retire só os espaços das pontas; preserve os do meio.
    texto_limpo = texto.strip()
    # Devolva o resultado para a chamada abaixo.
    return texto_limpo

produto = preparar_texto("  Caderno grande  ")
print(produto)
print(produto == "")  # A comparação responde se o texto ficou vazio.

Exemplo: parâmetro, condição e retorno
def saudar(apelido):
    apelido = apelido.strip()
    if apelido:
        return f"Olá, {apelido}!"
    return "Olá, visitante!"

print(saudar("  Sol  "))
print(saudar("   "))

O argumento muda entre as chamadas; a função devolve uma mensagem. Rastreie cada chamada antes de usar o terminal.

Exemplo: conversão e erro específico
texto = "abc"
try:
    quantidade = int(texto)
    print(quantidade)
except ValueError:
    print("Não foi possível converter esse texto em inteiro.")

Troque abc por 12 e execute novamente. Observe qual bloco é percorrido. A conversão sozinha não verifica se um número atende a uma regra do aplicativo.

Regras e detalhes para consultar durante o desafio

Acompanhe a demonstração no terminal. Antes de cada execução, preveja a saída e depois compare com a observação. O professor usará exemplos diferentes do cadastro para apresentar funções e condições.

Arquitetura desta aula: texto digitado → função de conferência → mensagem. Na janela, o callback obtém os textos e atualiza o rótulo. Não há classes próprias, banco ou arquivo de cadastro. Dependências: biblioteca padrão do Python e Tkinter/ttk.

Função reúne uma tarefa nomeada: def declara a função, o parâmetro recebe uma entrada e return devolve um resultado. A indentação delimita seus blocos. if só executa seu bloco quando a condição é verdadeira. Abra os exemplos depois de prever a saída.

strip retira espaços apenas das pontas; não remove espaços entre palavras. int tenta converter o texto em inteiro. Se essa conversão não for possível, ValueError sinaliza o problema. Um except específico permite orientar a pessoa sem esconder todos os tipos de erro.

intervalo e exposição 2 ↗

1. Problema concreto

O cadastro já funciona no terminal. Como fazer a conferência acontecer somente quando alguém clicar no botão?

2. Entenda a ideia

A janela organiza a interação: Label mostra um texto, Entry permite digitar e Button recebe um clique. Tk cria a janela principal; mainloop mantém o programa esperando ações.

Callback é a função que o botão chamará depois. Em command=conferir_cadastro, entregamos a função. Com parênteses, ela seria executada naquele momento, durante a montagem da janela.

No clique, get() lê o conteúdo atual de uma Entry. Depois, configure(text=...) muda o texto de um Label. Você pode testar esse caminho com uma mensagem simples antes de acrescentar a validação.

grid posiciona cada elemento por linha e coluna. Primeiro verifique leitura e resposta; depois confira organização, rótulos e uso pelo teclado.

3. Exemplo comentado

Guardar uma função e chamar depois
def responder(texto_digitado):
    # Neste ensaio, o argumento faz o papel do texto lido no campo.
    return "Recebi: " + texto_digitado

acao_do_botao = responder  # Guarde a função sem chamá-la agora.
print(acao_do_botao("Teste"))  # Aqui simulamos o clique.

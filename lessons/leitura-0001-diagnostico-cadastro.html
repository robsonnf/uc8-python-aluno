A01 — Do terminal ao primeiro formulário

Revisar entradas, funções e condições para construir um cadastro fictício com nome e idade, primeiro no terminal e depois em uma janela.

Os dados conferidos ficam somente nesta sessão, sem gravação em arquivo ou banco. Baixe seus arquivos e exporte os registros antes de sair.

Aluno

Identificação e registros

Objetivos

  • Identificar o interpretador Python e verificar a disponibilidade de Tkinter.
  • Explicar o caminho entrada → validação → resposta em uma função.
  • Construir um formulário com dois campos rotulados e um botão ligado a uma função.
  • Rejeitar nome vazio e idade inválida com mensagem compreensível.
  • Registrar casos de teste e explicar por que o resultado não é permanente.

Antes de começar

  • Computador com Python e VS Code previamente preparados; nenhuma biblioteca adicional é necessária nesta aula.
  • Conseguir abrir uma pasta, salvar um arquivo .py e abrir o terminal; solicite apoio se necessário.
  • Conhecimentos anteriores de variáveis e condições serão diagnosticados; não é preciso conhecer classes.

exposição 1: ler, prever e executar ↗

Acompanhe a demonstração no terminal. Antes de cada execução, preveja a saída e depois compare com a observação. O professor usará exemplos diferentes do cadastro para apresentar funções e condições.

Arquitetura desta aula: texto digitado → função de conferência → mensagem. Na janela, o callback obtém os textos e atualiza o rótulo. Não há classes próprias, banco ou arquivo de cadastro. Dependências: biblioteca padrão do Python e Tkinter/ttk.

Função reúne uma tarefa nomeada: def declara a função, o parâmetro recebe uma entrada e return devolve um resultado. A indentação delimita seus blocos. if só executa seu bloco quando a condição é verdadeira. Abra os exemplos depois de prever a saída.

strip retira espaços apenas das pontas; não remove espaços entre palavras. int tenta converter o texto em inteiro. Se essa conversão não for possível, ValueError sinaliza o problema. Um except específico permite orientar a pessoa sem esconder todos os tipos de erro.

  1. Preparar

    Abra uma pasta A01 no VS Code. No terminal, confira python --version e python -m tkinter. Feche a janela demonstrativa após registrar a versão. Se o módulo faltar, chame o professor para verificar a distribuição do Python.

  2. Ler

    input e Entry.get obtêm texto. Observe aspas, variáveis, indentação, parâmetros e return. Diga o que cada linha recebe ou produz.

  3. Prever

    Compare uma condição verdadeira e falsa. Observe strip retirando espaços das pontas de um texto e int tentando transformar texto em inteiro.

  4. Executar e interpretar

    Observe ValueError em uma conversão incompatível e o caminho do try/except. Localize o erro e descreva uma mensagem que ajude a pessoa a corrigir a entrada.

Exemplo: texto e número
idade_texto = "18"
idade_numero = 18
print(idade_texto + "1")
print(idade_numero + 1)

Compare concatenação de texto e soma de números. Antes de executar, anote as duas saídas que espera.

Exemplo: parâmetro, condição e retorno
def saudar(apelido):
    apelido = apelido.strip()
    if apelido:
        return f"Olá, {apelido}!"
    return "Olá, visitante!"

print(saudar("  Sol  "))
print(saudar("   "))

O argumento muda entre as chamadas; a função devolve uma mensagem. Rastreie cada chamada antes de usar o terminal.

Exemplo: conversão e erro específico
texto = "abc"
try:
    quantidade = int(texto)
    print(quantidade)
except ValueError:
    print("Não foi possível converter esse texto em inteiro.")

Troque abc por 12 e execute novamente. Observe qual bloco é percorrido. A conversão sozinha não verifica se um número atende a uma regra do aplicativo.

prática 1: cadastro no terminal ↗

Trabalho individual com troca de explicações e feedback. Use somente nomes e idades fictícios. O contrato é: nome com texto após retirar espaços das pontas e idade inteira maior que zero. Nome composto é permitido. Não é necessário consultar idade real ou documento.

Faça uma tentativa, execute um caso por vez e registre previsão e observação. Depois ajuste. Não use uma mensagem de sucesso para entradas recusadas.

intervalo e exposição 2 ↗

Após o intervalo, demonstração ao vivo da janela. Observe uma Tk, widgets ttk e um mainloop. grid posiciona cada elemento por linha e coluna; sticky e columnconfigure ajudam a distribuir o espaço.

Label identifica o campo; Entry recebe texto; Button dispara uma função e Label apresenta a mensagem. get lê o texto no momento do clique. command recebe a função que será chamada depois. Observe o professor conectar um botão a uma ação simples antes de adaptar o cadastro.

Use rótulos explícitos e mensagens em texto, sem depender apenas da cor. Percorra os campos com Tab e Shift+Tab. Antes de testar, confira qual arquivo e interpretador serão executados.

Exemplo isolado: um botão muda uma mensagem
import tkinter as tk
from tkinter import ttk

janela = tk.Tk()
janela.title("Um evento")

def responder():
    mensagem.configure(text="O clique chamou a função.")

mensagem = ttk.Label(janela, text="Aguardando clique.")
mensagem.grid(row=0, column=0, padx=12, pady=12)
ttk.Button(janela, text="Experimentar", command=responder).grid(row=1, column=0, pady=12)
janela.mainloop()

Salve separadamente como evento.py para acompanhar a demonstração. command recebe responder sem parênteses; a função será chamada no clique. Este exemplo ainda não lê nem valida um cadastro.
